# Карта проекта и архитектура сайта (PROJECT_MAP)

> **Назначение документа:** Быстрый ввод в контекст любого агента при старте новой сессии. Документ содержит полную структуру сайта, архитектуру верстки, дизайн-систему, карту селекторов и стек инструментов. Прочитав этот файл, агент сразу знает, где что лежит, без необходимости листать тысячи строк исходников.

---

## 1. Стек технологий и установленные инструменты

* **Фронтенд:** Чистый семантический HTML5, чистый модульный CSS3 (Custom Properties, Flexbox, Grid, `clamp()`), чистый ES6+ JavaScript (без тяжелых фреймворков и лишних зависимостей).
* **Шрифты:** Google Fonts — `Manrope` (главный заголовок Hero), `Plus Jakarta Sans` (основной UI и заголовки) + `Newsreader` (редакционные курсивные акценты).
* **Системные CLI-инструменты на машине пользователя:**
  * `ripgrep` (`rg`) v15.2+ — **главный инструмент быстрого поиска** по кодовой базе и CSS-селекторам.
  * `Node.js` v24.14+ и `npm` 11.19+.
  * `Python` 3.14 с установленными `Pillow` (PIL) и `Playwright`.
  * `Playwright (Chromium)` — инструмент для обязательной единичной финальной проверки рендера.
  * `PhotoCraft` (`tools/photocraft/`) — реверс-инжиниринговый аналог Adobe Photoshop (`photocraft.exe` GUI, `photocraft-cli.exe` CLI для послойной обработки PSD/PNG).

## 4. Дизайн-система и токены (CSS Custom Properties)

* **Цветовая палитра:**
  * Фон Hero и сайта: `#080B10` (глубокий темный премиальный фон).
  * Основной синий акцент: `#2563EB` (кнопки, активные элементы), градиент `#60A5FA` -> `#2563EB`.
  * Текст: `#FFFFFF` (заголовки), `rgba(255, 255, 255, 0.85)` (основной текст), `rgba(255, 255, 255, 0.65)` (второстепенный).
  * Секция контактов: светлая гамма (белые карточки `#FFFFFF`, темный контрастный текст `#0F172A`, мягкие тени).
* **Геометрия и отступы:**
  * Скругления: `--radius-pill: 9999px` для кнопок и бейджей, `16px–24px` для карточек.
  * Максимальная ширина контента: `1440px`.
* **Принцип 100% резиновой и адаптивной верстки (Cross-DPI & Scale Invariance):**
  * Сайт обязан выглядеть **визуально идентично** на любых ноутбуках, мониторах и при любых настройках масштабирования Windows (100%, 125% — логические 1536px, 150% — логические 1280px).
  * Если текстовый блок (например, H1 на первом экране) выстроен в строгое число строк, строки **всегда фиксируются жесткими `<br>`**, а не надеждой на автоперенос браузера. «Мягкий» перенос при масштабе 125% растягивает блок и ломает верстку.
  * Размеры шрифтов и отступы рассчитываются через `clamp()`, `vh`, `vw`, привязываясь к пропорциям и геометрии фоновых объектов.

## 5. Главные рабочие сценарии для агента

1. **Поиск нужного селектора или текста:**
   * Не листать весь `style.css`! Выполнить: `rg -n "нужный_селектор" style.css`.
   * Открыть точный диапазон строк через `view_file(StartLine, EndLine)`.
2. **Внесение правок:**
   * Менять код точечно через `replace_file_content`.
   * При изменении `style.css` обязательно обновлять версию кэша в `index.html` (`style.css?v=...`).
3. **Финальная проверка:**
   * Запустить Playwright через однострочный скрипт Python, сохранить скриншот в артефакты (`<appDataDir>/brain/<conversation-id>/`).
   * Проверять верстку с учетом ноутбучных масштабов Windows (например, 1536×864 при 125% DPI или 1440×900).
   * Лично посмотреть скриншот через `view_file`.
   * Выдать результат пользователю.
